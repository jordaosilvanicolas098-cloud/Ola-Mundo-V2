# 🐍 Olá Mundo V2

## Programação, criatividade e uma conversa com Tim Peters

Este projeto é uma evolução do meu primeiro Olá Mundo em Python. Nesta segunda versão, decidi misturar programação, humor e filosofia, utilizando como inspiração os 19 princípios do Zen de Python.

## 💻 Conhecimentos praticados

- Variáveis
- Strings
- Entrada de dados (input)
- Saída de dados (print)
- Interação com o usuário
- Respostas automáticas
- Git e GitHub Desktop

## 🧠 Uma brincadeira com Tim Peters

**Princípio do Zen de Python:**

> Erros nunca devem passar silenciosamente.

**Minha resposta:**

> Os meus erros sempre vêm à tona, mas sempre busco evitá-los.

Afinal, até os erros fazem parte da evolução de um programador.

## 🛠️ Ferramentas utilizadas

- Python
- Python IDLE
- PyCharm
- Git
- GitHub Desktop

## 📈 Evolução do projeto

- V1 — Primeiros passos na programação Python.
- V2 — Interatividade, respostas automáticas, criatividade e referências ao Zen de Python.

## 🎯 Objetivo

Documentar minha evolução na programação, desenvolver meu raciocínio lógico e transformar pequenos projetos em experiências de aprendizado.
